# contributing

small prs welcome.

## build

see [build from source](README.md#build-from-source). the project is `PromptAnnotator.xcodeproj`, scheme `PromptAnnotator` (the old internal name, the app ships as "da transcribuh").

## test

```sh
xcodebuild test -project PromptAnnotator.xcodeproj -scheme PromptAnnotator \
  -derivedDataPath build CODE_SIGN_IDENTITY=-
```

## pr notes

- keep it small. one thing per pr
- ui change? drop a before/after screenshot in the pr
- leave release signing alone (`Config/Release.xcconfig`, `scripts/release.sh`). that's for shipping builds, see [docs/releasing.md](docs/releasing.md)
- readme images are generated by `docs/readme/render.py` (needs playwright + pillow). rerun it, don't hand edit the pngs
